为什么 B站、酷安等 App 依然有开屏广告？（原理解析与避坑指南）
  • 第一方业务接口混载：B站（哔哩哔哩）、知乎等开屏物料直接从其核心 API（如 app.bilibili.com）下发，素材存放在 hdslb.com 等官方 CDN。路由器在 DNS 层面无法单独封禁广告而不破坏正常视频/图片播放。
  • 内置 HttpDNS / 强缓存：酷安等 App 内置了腾讯/阿里 HttpDNS（通过 HTTPS 直连 IP，如 119.29.29.29）绕过局域网 DNS，并将广告物料保存在手机内部持久化数据目录（仅清理系统“缓存 Cache”无法删除）。
  • 手机开启了“私人 DNS”：华为、小米、OPPO、vivo 等安卓系统若开启了“私人 DNS (DoT)”，手机请求会强制走公网 DoT 服务器，完全绕过路由器 SmartDNS。
完美去广告终极指南： ① 请将手机设置中的【私人 DNS / 安全 DNS】设为关闭；② 强烈建议配合手机端无障碍跳过工具（如李跳跳或 GKD），路由器负责阻断第三方数据追踪 + 客户端无障碍秒点跳过，实现完美开屏无感！
