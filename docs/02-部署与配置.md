# 02 · 部署与配置（Web 控制台）

> **仅适用于 Linksys FGW3000-HK。**
> 前提：已完成 [01-开启Telnet和SSH](01-开启Telnet和SSH.md)，拿到 root 权限。

---

## 一、部署前端（必须）

把 `dashboard/` 下的 4 个文件传到设备 `/mnt/jffs2/log/`：

```sh
# dashboard.html  api.cgi  sms.html  sms_api.cgi  ->  /mnt/jffs2/log/
chmod +x /mnt/jffs2/log/api.cgi /mnt/jffs2/log/sms_api.cgi
```

确认 lighttpd 有别名 `/weblog/` → `/mnt/jffs2/log/`（`/etc/lighttpd/lighttpd.conf`，
原厂一般已配好）：

```
alias.url += ("/weblog/" => "/mnt/jffs2/log/")
```

访问：**`http://192.168.15.1/weblog/dashboard.html`**

> 上传方式：可用 scp / 你惯用的脚本。设备可写分区 `/mnt/jffs2` 很小（约 13MB），
> 别塞大文件。

---

## 二、部署后端脚本（按需）

`dashboard/backend/` 里的脚本是面板功能的"执行者"，放到设备对应位置：

```sh
/mnt/jffs2/startup.sh                       # 开机自启 / 编排 / 自愈
/mnt/jffs2/auto_carrier.sh                  # 切运营商 / 频段
/mnt/jffs2/proxy/proxy_watchdog.sh          # 15 秒保活看门狗
/mnt/jffs2/proxy/gen_config.sh              # 生成 sing-box 配置
/mnt/jffs2/proxy/dnsmasq_wrapper.sh         # DNS 拦截 Wrapper

chmod +x /mnt/jffs2/startup.sh /mnt/jffs2/auto_carrier.sh /mnt/jffs2/proxy/*.sh
sh /mnt/jffs2/startup.sh    # 手动跑一次验证
```

`startup.sh` 首次运行会把自己注入 crontab（每分钟执行，`chattr +i` 防篡改）。

## 三、你还需要自备的组件（本项目不含二进制）

| 组件 | 放到 | 说明 |
| --- | --- | --- |
| `sing-box` | `/mnt/jffs2/proxy/sing-box` | aarch64 静态，官网下载；代理核心 |
| `smartdns` | `/mnt/jffs2/proxy/smartdns` | 可选；DNS 加速 |
| Anti-AD 规则 | `/mnt/jffs2/proxy/anti-ad.conf.gz` | 可选；去广告规则库 |

> 二进制请从各项目官方渠道获取（本项目只提供脚本与面板，不打包第三方二进制）。

## 四、⭐ 按需配置（只开你要的功能）

系统是**模块化**的，可只部署一部分：

### 场景 A：只要「蜂窝控制」（锁频 / 切运营商 / 看信号）——最轻量

- 部署：前端 4 文件 + `auto_carrier.sh` + `startup.sh`
- **不放**：sing-box / smartdns / anti-ad
- 效果：能锁频段、切运营商、看信号温度；代理页自然为空。

### 场景 B：只要「代理」（不要 DNS 加速 / 去广告）

- 部署：前端 4 文件 + `startup.sh` + `proxy_watchdog.sh` + `gen_config.sh` + `sing-box`
- **不放**：smartdns / anti-ad / dnsmasq_wrapper.sh
- `startup.sh` / `proxy_watchdog.sh` 会**检测到没有 smartdns 就自动跳过 DNS 收敛**，
  保持原厂 DNS，**不会断网**。
- 效果：代理能开能用，DNS 保持原厂默认。

### 场景 C：全功能（代理 + DNS 加速 + 去广告）

- 全部部署，备齐 `sing-box` + `smartdns` + `anti-ad.conf.gz`
- 运行 `startup.sh` 会自动拉起 SmartDNS、dnsmasq 兜底、sing-box、看门狗。

### 临时关掉某功能

- **关代理**：面板代理开关（或 `POST api.cgi?action=proxy_toggle` 带 `enable=0`）
- **关去广告**：面板 AdBlock 开关（写入 `config.json` 的 `"adblock_enabled": false`）

## 五、后端接口一览（`api.cgi`）

`GET/POST /weblog/api.cgi?action=<动作>`：

| action | 作用 |
| --- | --- |
| `get_cellular` | 读蜂窝信号 / 系统资源 / DNS 状态 |
| `set_carrier` | 切运营商（`op=ct\|cmcc\|cu\|ct_4g`） |
| `set_bands` | 锁定 5G/4G 频段 |
| `proxy_status` | 读代理状态与配置 |
| `proxy_toggle` | 开关代理（`enable=1/0`） |
| `save_proxy_config` / `save_runtime_config` | 保存代理配置 |
| `switch_node` | 切换当前节点 |
| `fetch_sub` | 拉取机场订阅 |
| `test_delay` | 测节点延迟（ICMP ping 节点服务器，≈ 手机 App 口径） |
| `get_outbound_ip` | 查代理出口 IP |
| `smartdns_restart` | 重启 SmartDNS |
| `adblock_check` | 查 / 管去广告 |

短信：`sms_api.cgi?action=status|send|delete`（需基带支持）。
