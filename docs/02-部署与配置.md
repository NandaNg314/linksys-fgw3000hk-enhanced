# 02 · 部署与配置（Web 控制台）

> **仅适用于 Linksys FGW3000-HK。**
> 前提：已完成 [01-开启Telnet和SSH](01-开启Telnet和SSH.md)，拿到 root 权限。

---

## 一、部署前端（必须）

把 `dashboard/` 下的 4 个文件传到设备 `/mnt/jffs2/log/`：

```sh
# dashboard.html  api.cgi  sms.html  sms_api.cgi  ->  /mnt/jffs2/log/
chmod +x /mnt/jffs2/log/api.cgi /mnt/jffs2/log/sms_api.cgi
```

确认 lighttpd 有别名 `/weblog/` → `/mnt/jffs2/log/`（`/etc/lighttpd/lighttpd.conf`，
原厂一般已配好）：

```
alias.url += ("/weblog/" => "/mnt/jffs2/log/")
```

访问：**`http://192.168.15.1/weblog/dashboard.html`**

> 上传方式：可用 scp / 你惯用的脚本。设备可写分区 `/mnt/jffs2` 很小（约 13MB），
> 别塞大文件。

---

## 二、部署主路由后端脚本（AP `192.168.15.1`）

`dashboard/backend/` 里的脚本部署到主路由 `/mnt/jffs2/` 对应位置：

```sh
/mnt/jffs2/startup.sh                       # 开机自启 / 挂载保护 / 防火墙隔离 / 全局保活
/mnt/jffs2/net_orchestrator.sh              # 5G/4G WAN Raw-IP 双栈自愈、MHI 假死智能复位与跳变黑匣子
/mnt/jffs2/auto_carrier.sh                  # 四大运营商自动识别与 ≤5 频段安全收敛配置
/mnt/jffs2/deploy_to_modem.exp              # 基带 HTTP/Telnet 与自启链巡检恢复
/mnt/jffs2/read_sms.sh                      # 统一读取基带 4G/5G IMS 短信收件箱
/mnt/jffs2/delete_sms.sh                    # 单条/批量/清空删除短信（含 IMS 幂等防复活）
/mnt/jffs2/sms_forwarder.sh                 # 短信验证码提取与多渠道推送守护（防断网吞信）
/mnt/jffs2/proxy/proxy_watchdog.sh          # 15 秒高频看门狗（DNS 双保险 + 日志容量截断）
/mnt/jffs2/proxy/dnsmasq_wrapper.sh         # 剥离 except-interface=lo 并保留 223.5.5.5 兜底
/mnt/jffs2/proxy/smartdns.conf              # SmartDNS 公共上游优选参考配置
/mnt/jffs2/proxy/gen_config.sh              # 生成 sing-box 配置（按需启用代理时使用）

chmod +x /mnt/jffs2/*.sh /mnt/jffs2/proxy/*.sh
sh /mnt/jffs2/startup.sh                    # 手动执行一次验证
```

`startup.sh` 首次运行会注入精简 `crontab`（移除原厂凌晨 `02:30 fota_alarm` 扰动，施加 `chattr +i` 防篡改锁），并将 `subsys0/restart_level` 锁定为 `SYSTEM`。

## 二·五、部署基带侧 SGs / QMI WMS 短信、QoS 与可选 5G IMS 模块（Modem `10.10.10.3`）

在推荐的 **5G NSA (`EN-DC`, `sa_mode=1`) / 4G 单 PDN 稳态模式** 下，主路由通过 `lte_mgr_csps`（`CS+PS` 联合附着）直接开启原生 SGs 信令收发短信，基带 `/data/parse_sms.pl` 通过 QRTR `QMI WMS 0x0031` 零阻塞预检 SIM/NV 槽位（日常 0 次打开 `/dev/smd7`），**默认无需启动第二条 `ims` PDU 会话**，彻底规避港版 SDX55 固件在 5G SA 并发双 PDU 会话下的 MPSS `-110` 死锁风险：

1. 将 `modem/scripts/` 传入基带 `/data/`（`oem_init_post.sh`, `probe_ambr.pl`, `parse_sms.pl`, `del_sms.sh`, `send_sms.pl`），将 `modem/cgi-bin/` 传入 `/data/www/cgi-bin/`（`aka`, `ims_info`, `ims_sip_ctl`, `cell_qos`, `sms`, `delete_sms`, `send_sms`），统一执行 `chmod +x`。
2. 确保基带 `/oem/script/oem_init_post.sh` 末尾包含 `sh /data/oem_init_post.sh &`（主路由 `deploy_to_modem.exp` 亦会在开机自动巡检恢复）。
3. **（可选，仅纯 5G SA 且无 SGs 回落环境按需启用）**：按 [`modem/ims_sip/README.md`](../modem/ims_sip/README.md) 交叉编译 `ARMv7` 静态二进制 `ims_sip` 上传至 `/data/ims_sip`，并在基带创建 `/data/.enable_ims_sip`（及主路由 `/mnt/jffs2/conf/user/.enable_ims_sip`）显式开启。

## 四、⭐ 按需配置（只开你要的功能）

系统是**模块化**的，可只部署一部分：

### 场景 A：只要「蜂窝控制」（锁频 / 切运营商 / 看信号）——最轻量

- 部署：前端 4 文件 + `auto_carrier.sh` + `startup.sh`
- **不放**：sing-box / smartdns / anti-ad
- 效果：能锁频段、切运营商、看信号温度；代理页自然为空。

### 场景 B：只要「代理」（不要 DNS 加速 / 去广告）

- 部署：前端 4 文件 + `startup.sh` + `proxy_watchdog.sh` + `gen_config.sh` + `sing-box`
- **不放**：smartdns / anti-ad / dnsmasq_wrapper.sh
- `startup.sh` / `proxy_watchdog.sh` 会**检测到没有 smartdns 就自动跳过 DNS 收敛**，
  保持原厂 DNS，**不会断网**。
- 效果：代理能开能用，DNS 保持原厂默认。

### 场景 C：全功能（代理 + DNS 加速 + 去广告）

- 全部部署，备齐 `sing-box` + `smartdns` + `anti-ad.conf.gz`
- 运行 `startup.sh` 会自动拉起 SmartDNS、dnsmasq 兜底、sing-box、看门狗。

### 临时关掉某功能

- **关代理**：面板代理开关（或 `POST api.cgi?action=proxy_toggle` 带 `enable=0`）
- **关去广告**：面板 AdBlock 开关（写入 `config.json` 的 `"adblock_enabled": false`）

## 五、后端接口一览（`api.cgi`）

`GET/POST /weblog/api.cgi?action=<动作>`：

| action | 作用 |
| --- | --- |
| `get_cellular` | 读取蜂窝射频（含 `nr_bwp_mhz` / `nr_rank` / `nr_cqi`）、QMI `5QI/QCI`、5GSM 签约速率（`ambr_dl_mbps` / `ambr_ul_mbps`）、5G `ims` 在线状态与系统资源 |
| `set_carrier` | 切运营商（`op=ct\|cmcc\|cu\|cbn\|ct_4g`） |
| `set_bands` | 收敛锁定 5G/4G 频段（建议总数 ≤ 5） |
| `get_sms` / `send_sms` / `delete_sms` / `delete_all_sms` | 统一读写删 4G 与 5G IMS 短信收件箱 |
| `get_forward_config` / `save_forward_config` / `test_forward` | 管理与测试多渠道短信转发（PushPlus / SMTP / Bark / Telegram / Webhook） |
| `proxy_status` / `proxy_toggle` | 读取与开关透明代理（可选模块） |
| `smartdns_restart` / `adblock_check` | 管理 SmartDNS 与去广告规则状态 |

短信：`sms_api.cgi?action=status|send|delete`（需基带支持）。
